## 交互

- **总览**：海岛图与首页背景相连，点击图中的欧胡、Hilo、Kona 进入对应行程；下方按地区浏览十天安排。
- **每日行程**：默认只显示时间与安排名称。点一站打开详情面板，在面板内切换前后站点、查看提醒和地图。手机使用底部弹出面板，桌面使用对话框。
- **切换日期**：十个日期直接排在页面上方，当前日期高亮。手机横向滑动选择，日期栏滚动时固定在顶部；桌面一次显示全部日期。每一天都有可分享的 `#day-YYYY-MM-DD` 链接。
- **吃住交通**：当天页首一键查看餐食、酒店地图、用车和待确认事项；不再在每日列表里重复展示。
- **全站导航**：只保留旅程、地图、资料三个入口；网站标志回到总览。
- **地点地图**：地区筛选、名称搜索、地图入口及 CSV 下载。地图只包含有明确名称的地点，不把未确定的集合点当成导航目的地。
- **出行资料**：已预订及候选航班、酒店、租车和按天整理的待确认事项，不含个人身份资料或订单凭证。

## 本地预览

在项目目录执行 `python3 -m http.server 4173 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:4173`。

## 更新

- `data.js`：每日路线、时间、餐饮、注意事项、航班状态、酒店和租车。
- `app.js`：页面与详情面板的交互。
- `styles.css`：手机和桌面布局，包含安全区、键盘焦点、减少动画及打印样式。
- `assets/`：本站绘制的路线示意图和图标。路线示意不按地理比例绘制，不用于导航。

字体通过 Google Fonts 提供，无法联网时使用设备字体。地图链接打开 Google Maps；全站无需地图 API 密钥，不使用分析追踪。

## GitHub Pages

将本仓库的 `main` 分支根目录设为 GitHub Pages 发布来源即可。所有本地资源使用相对路径，支持 `/hawaii-2026/` 项目路径。仓库中不包含需要提交的构建产物。
